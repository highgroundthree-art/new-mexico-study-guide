# New Mexico Esthetician Exam Study Kit

Study materials for the New Mexico esthetician licensing exams: a study guide, flashcards, and practice quizzes at four levels. Students start at Level 1 and move up one level at a time, so each step feels within reach.

## What's inside

| File | What it is |
| --- | --- |
| `index.html` | Interactive Study Lab: flip flashcards, self-scoring quizzes for all four levels, and the test blueprint |
| `STUDY-GUIDE.md` | Study guide organized by exam section |
| `FLASHCARDS.md` | 48 industry terms, each explained at Levels 1 to 4 |
| `flashcards.csv` | The same flashcards as a spreadsheet, for printing or importing into a flashcard app |
| `quiz-level-1.md` to `quiz-level-4.md` | Printable practice quizzes, 25 questions each |
| `ANSWER-KEY.md` | Answers and short explanations for all four quizzes |

## The four levels

| Level | Style |
| --- | --- |
| 1 | Short, clear questions to build the basics |
| 2 | Exam-style questions using the real vocabulary |
| 3 | Questions that ask why and how |
| 4 | Real-world scenarios like the ones on the state exam |

Every quiz follows the written exam's weighting: 14 Scientific Concepts questions and 11 Skin Care and Services questions (about 55% and 45%). A score of 18 out of 25 (70%) meets the passing mark. Move up a level after reaching it.

## Using the Study Lab

Open `index.html` in any browser. To put it online with GitHub Pages:

1. In the repository, open **Settings**, then **Pages**.
2. Under **Branch**, choose `main` and the `/ (root)` folder, then save.
3. After a minute or two, the page is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## About these materials

This is an unofficial study aid based on the NIC National Esthetics exam outline and New Mexico's rules (16.34 NMAC) as of November 2026. Exam content and rules change. Confirm current requirements with Professional Credential Services (PCS) and the New Mexico Board of Barbers and Cosmetologists.
